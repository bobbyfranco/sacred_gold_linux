# sacred_gold_linux
A DRM free installer for the PC game Sacred Gold ported Linux.

## Requirements:
```
- Linux with Bash.
- Python 3.8 or newer.
- tar with Zstandard support, plus the zstd command.
- At least 3 GiB of free space on the destination drive, in addition to the existing 1.9 GB installer.
- Write permission for the installation folder’s parent directory. The destination folder must not already exist.

Optional dependencies:

- Zenity for graphical installation dialogs; otherwise it uses terminal prompts.
- update-desktop-database to refresh the applications menu.

Root access isn’t required when installing into your home directory.
```
